## Что остаётся как в эталоне

В эталоне не заданы реальные Instagram, email и размеры коробок двух наборов. Значения не придуманы. У части демотоваров нет фотографий; для них сохранены исходные заглушки. Карточки эталона также показывают пустые дополнительные миниатюры, если фотографий меньше трёх. Автоматическая отправка заявки и онлайн-оплата не подключены: посетитель отправляет подготовленный текст вручную.

Для локального просмотра нужен только Python 3:

```sh
cd /workspace/darya-handmade
python3 -m http.server 8001 --bind 127.0.0.1 --directory /workspace/darya-handmade
```

Не отправляйте ветку в GitHub без отдельного согласования: интеграция Vercel может автоматически запустить preview deployment. Установка зависимостей и сборка для этого статического сайта не требуются.
