# Darya Mucha · /versionigor

Новая галерея изолирована в `/versionigor`. Рабочая ветка: `review/versionigor-blob`. Главная `index.html`, все её товары, встроенные фотографии и `assets/legacy` не изменены. В `main` изменения не внесены.

## Что реализовано

Молочный фон, угольная типографика, крупные квадратные изображения без обрезки, две колонки на desktop и одна на mobile. Отдельные чёрные полноэкранные страницы работ и обращений; прямые ссылки, Back/Forward, Escape, возврат прокрутки и фокуса. RU/EN доступны и внутри слоёв. На touch первый тап раскрывает карточку, второй открывает работу.

Актуальные 14 реальных работ с опубликованной главной, включая «Узел судьбы», перенесены в структурированный каталог. Старый Git-каталог из 21 товара сохранён в исходной главной. Демонстрационные работы не выдаются за новые реальные произведения.

Заполненные серии: «Мифы Японии», «Обыкновенные монархи», «Тихие чудеса», «Маленькие торжества». Истории на двух языках обозначены как галерейное прочтение, не документированный авторский замысел. Даты создания не выдуманы; порядок редакционный. Неизвестные размеры наборов показываются как «Уточнить при обращении».

Источник каталога и первоначальные цены: `versionigor/assets/data/source-catalog.json`. Рабочий каталог: `catalog.json`. Список изменений цен: `price-changes.json`: 8 картин 25 000 → 24 900 RUB; 4 работы в гипсовых рамках 5 000 → 4 900 RUB; два набора 2 500 / 3 500 RUB без изменения. Цены главной не менялись.

## Медиа и шрифты — только darya-media

**Импорт пока не выполнен.** В выполняющейся среде отсутствует `BLOB_READ_WRITE_TOKEN`; сохранённая привязка `VERCEL_TOKEN` получает 403 для scope `darya23`. Нельзя объявлять пустые папки успешно перенесёнными файлами. `media.json` содержит честный статус `awaiting-access`.

В защищённых настройках среды подготовлено поле `BLOB_READ_WRITE_TOKEN`. Нужен токен именно хранилища **darya-media** с доступом к `blob.vercel-storage.com`. Значение не вводят в чат, Git, сайт или `site.json`. После сохранения и применения настроек:

```sh
python3 scripts/sync-blob-media.py
node scripts/check-gallery-media.cjs
```

Для работы с `.env.local` импортёр также автоматически читает **только** `BLOB_READ_WRITE_TOKEN` из файла в корне проекта. Пример без секрета — `.env.example`; локальный `.env.local` подготовлен с пустым значением. Файл на вашем компьютере не появляется автоматически в облачной среде Codex: здесь удобнее заполнить защищённое поле «Среда → Сетевые секреты → BLOB_READ_WRITE_TOKEN», скопировав только значение после `=` из полученного в Vercel файла. Не прикреплять файл с настоящим токеном к чату. Привязка среды имеет приоритет над локальным файлом; `.env.local` исключён из Git и публикации. Импортёр не исполняет shell-команды из dotenv.

Импорт делает только GET-запросы: получает полный список с пагинацией и скачивает медиа/шрифты в `versionigor/assets/media` и `versionigor/assets/fonts`, сохраняя структуру Blob. Он не меняет удалённые объекты и не перезаписывает отличающиеся локальные файлы. В манифесте сохраняются публичный источник, размер и SHA-256; содержимое секретов не сохраняется. API version 12 сверена с установленным официальным `@vercel/blob`.

Также поддерживается `--manifest /path/to/blob-list.json` с настоящим списком публичных Blob URL. Частные хранилища и подписанные URL не превращаются в публичные ссылки автоматически.

Имена брендовых файлов: `medasha.png`, `logodasha.png`, `signdasha.png`, `favidasha.jpg`, `manuscript.ttf`. Их присутствие ещё не подтверждено списком хранилища. Отсутствующие изображения не подменяются фотографиями из старого HTML, случайными фото или генерациями. До импорта показано состояние недоступного изображения, шрифт — системный sans-serif.

Фото сопоставляются товарам автоматически только при точном совпадении SHA-256 с исходными изображениями. Для перекодированных файлов требуется проверенное визуальное сопоставление и запись локальных путей в `media.json.products`. Не угадывать по порядку файлов. Перед публикацией проверить все фото, прозрачность портрета, favicon, цифры и кириллицу manuscript.ttf; эти проверки пока заблокированы.

## Курсы и письма

`api/versionigor/rates.js` получает USD/EUR из официального XML ЦБ, учитывает Nominal и дату курса. Кеш на сервере — 6 часов, также есть браузерный кеш последнего успешного курса. При сбое показывается сохранённый курс с датой; без него эквиваленты не придумываются. В RU основная цена RUB, вторично EUR/USD; в EN только EUR либо запрос стоимости. Реальный запрос к ЦБ проверен: дата из ответа 2026-10-24, EUR 90.2429 RUB, USD 80.5381 RUB.

`api/versionigor/contact.js` отправляет письмо через Resend на **daria.mucha@gmail.com**. Для реальной отправки нужны серверные переменные **проекта Vercel**, без префикса PUBLIC:

| Переменная       | Назначение                                        |
| ---------------- | ------------------------------------------------- |
| `RESEND_API_KEY` | Ключ почтового сервиса с правом отправки          |
| `CONTACT_FROM`   | Подтверждённый отправитель вашего домена в Resend |

Сейчас они не настроены. Сервер возвращает 503, интерфейс сохраняет введённое и предлагает реальные Email/Telegram как резерв. Успех показывается только после ответа провайдера с ID письма. Реальное письмо во время проверки не отправлялось.

Проверяются размер тела, поля, формат выбранного контакта, ID работы, Origin, honeypot. Цена, название и серия берутся на сервере из каталога, а не из клиентской цены. Повторный запрос с тем же ключом не отправляет письмо повторно; Resend также получает Idempotency-Key. Лимит — 5 новых обращений / 15 минут / IP на тёплый экземпляр функции, адрес сохраняется только как хеш в памяти. Это не глобальный лимит между всеми экземплярами; при росте трафика добавить общее хранилище или Vercel Firewall. Самостоятельная инфраструктура ради неподключённой формы не создавалась.

Подтверждён Telegram `https://t.me/Daria_Alexsandrowna`. Instagram, Threads, Behance и LinkedIn не подтверждены и скрыты; CTA знакомства ведёт к разделу о художнице. Настоящие адреса можно добавить в `site.json.social`, без вымышленных профилей.

## Публикация и сохранение главной

`vercel.json` проверен официальным валидатором Vercel. Новые rewrites и headers относятся только к `/versionigor`; серверные функции лежат в `api/versionigor`. Прямые страницы работ получают title/description/canonical/Open Graph на сервере; неизвестная работа возвращает 404. Нет новых зависимостей приложения или сборки фронтенда. Документация, скрипты и тесты исключены из публикации через `.vercelignore`.

**Production не опубликован.** Текущий API Vercel запрещает доступ к существующему проекту `darya-handmade` в scope `darya23`. Дубликат проекта не создавался.

Действующий публичный `/` уже отличается от Git-копии. Нельзя продвигать сборку этого checkout в production с устаревшей главной. После импорта и проверки медиа:

```sh
python3 scripts/prepare-gallery-deploy.py
```

Скрипт создаёт каталог вне Git для деплоя, копирует код и берёт **текущую опубликованную главную байт в байт**, проверяя её локальные зависимости. Он не публикует ничего и не копирует `.git`, `.env` или секреты. Git-версия старой главной со всеми 21 товарами остаётся целой. Для публикации использовать этот подготовленный каталог, существующий project/team и восстановленный доступ Vercel. После публикации сравнить SHA-256 публичной главной с сохранённым свидетельством и проверить `/versionigor` и его прямые маршруты. Git-превью с устаревшей главной нельзя автоматически назначать production-домену.

На согласовании включён `noindex, follow` в HTML, JS-конфигурации и HTTP-заголовке. После утверждения переключение всех трёх мест одной командой:

```sh
python3 scripts/set-gallery-indexing.py approved
```

Обратно: `python3 scripts/set-gallery-indexing.py preview`. Команды сами ничего не публикуют.
