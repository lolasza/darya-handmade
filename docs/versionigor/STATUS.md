## Доступ к источнику

На момент проверки существующая привязка `VERCEL_TOKEN` присутствует, но API Vercel возвращает 403 `Not authorized` для scope `darya23`, включая запрос проекта и список storage stores. Источник Blob не заменяется медиа из старого HTML.

В черновик среды добавлено защищённое требование `BLOB_READ_WRITE_TOKEN` для `blob.vercel-storage.com`. Значения секретов не должны попадать в Git или чат. Доступ к Blob нужно повторно проверить после применения настроек; до этого `media.json` явно имеет статус `awaiting-access`, а URL и названия отсутствующих файлов не выдумываются.
