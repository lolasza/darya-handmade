# Прежние иллюстрации

Здесь сохранены четыре SVG-иллюстрации товаров `p6` и `p7` из версии проекта до переноса прикреплённого HTML. Они генерировались исходной функцией `demoArt` и сохранены без изменения содержимого.

В видимом каталоге эти товары используют иллюстрации правильной опубликованной версии. Файлы оставлены для сохранности прежних изображений по просьбе владельца; оформление опубликованной версии они не меняют.
